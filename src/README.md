# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share an activity via WhatsApp, Facebook, email, or a copied link

Activities can optionally include a `difficulty` field with the value
`Beginner`, `Intermediate`, or `Advanced`. Activities without this field are
for all levels. The difficulty filter's **All levels** option shows only those
activities, while **Any difficulty** shows activities regardless of level.
